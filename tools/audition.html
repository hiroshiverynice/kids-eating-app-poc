音の聴き比べ

⚔️ もぐもぐクエスト で使っている CC0 音源。緑が現在アプリで鳴っているもの。

ローカルサーバー経由で開いてください。
ファイルを直接ダブルクリック（file://）だと音が読み込めません。
リポジトリ直下で python -m http.server 8000 を実行し、 http://localhost:8000/tools/audition.html を開いてください。
差し替え方
気に入った候補が見つかったら、そのファイルを assets/audio/ の本番名に上書きコピーするか、 sodateru-shokutaku-poc.html の SFX_FILES テーブルのファイル名を書き換えてください。
その後 python derive.py を実行すると index.html / sodateru-tap.html に反映されます。

音量は同ファイル内の SFX_GAIN で個別に調整できます（0〜1）。
