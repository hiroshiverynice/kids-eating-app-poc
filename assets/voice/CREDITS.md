# 掛け声のクレジットとライセンス

このフォルダの音声は **VOICEVOX**（ソフトウェア）で合成した、**ずんだもん（あまあま）** の声です。

```
VOICEVOX:ずんだもん
```

## 音素材フォルダとの違い（重要）

`assets/audio/` と `assets/img/` の素材はすべて **CC0**（帰属表示が不要）ですが、
**このフォルダだけは違います。**

- VOICEVOX の利用規約により、**商用・非商用を問わずクレジット表記が必要**です。
- アプリの場合は「アプリの紹介画面など、少し探せばわかる場所」への記載が求められます。
- → **親メニュー（👪）の最下部にクレジット欄を置いています。**（`#credits`）
- クレジット表記をしない商用利用は、1キャラクターあたり年40万円（＋税）の契約が必要です。
  **表記さえすれば無料で商用利用できます。**

> `assets/audio/CREDITS.md` に「CC-BY の素材を足す場合は親画面にクレジット欄を追加すること」と
> 決めていたので、そのルールに従いました。

## 生成方法

`tools/gen_voice.py` で作り直せます。

```
1. VOICEVOX を起動（またはエンジンだけ: vv-engine/run.exe）
2. python tools/gen_voice.py
```

| 設定 | 値 |
|---|---|
| 話者 | ずんだもん / あまあま（speaker id = 1） |
| 抑揚 (intonationScale) | 1.25（掛け声なので強め） |
| 速度 (speedScale) | 0.97（幼児向けに気持ちゆっくり） |
| 形式 | Ogg Vorbis / モノラル / 40kbps（本数が多いので容量優先） |

## 中身

- `manifest.json` … 文言 → ファイル名の対応表。アプリはこれを読んで再生する
- `v001.ogg` 〜 … 掛け声344本（合計 約6.0MB）。**全14ゲームぶんを網羅**

アプリ側は manifest に**無い文言なら端末の合成音声にフォールバック**します
（オフラインや古い端末でも無音にしないため）。文言を増やしたら
`tools/gen_voice.py` の `LINES` に足して再生成してください。

**漏れの見つけ方**: 全14ゲームを実際に遊んで `speechSynthesis.speak` が
一度でも呼ばれたら、その文言が manifest に無いということです。
テスト `test_voice_all.mjs` がこれを自動で検出します（実際にこの方法で
「きらきらの サングラス！」「パーティコーデ かんせい！」「にじのチョウ が きた！」
「ぬしを つったよ！」の4系統の漏れが見つかりました）。
